# CLB Kết Nối – Trang web chính thức

> **Môn học:** Thiết kế Web (BTL_WED)  
> **Sinh viên:** Nguyễn Huy Hoàng – Thành viên CLB Kết Nối  
> **Trường:** Học viện Nông nghiệp Việt Nam (VNUA)

---

## 🌐 Giới thiệu dự án

Trang web giới thiệu **CLB Kết Nối** – câu lạc bộ tình nguyện trực thuộc Học viện Nông nghiệp Việt Nam. Trang được xây dựng bằng HTML và CSS thuần (không dùng framework), nhằm phục vụ mục đích học tập.

**Khẩu hiệu:** *We love and we do*

---

## 📁 Cấu trúc thư mục

```
BTL_WED/
├── index.html          # File HTML chính (toàn bộ nội dung trang)
├── style.css           # File CSS (toàn bộ giao diện, responsive)
├── README.md           # Tài liệu này
├── AI_LOG.md           # Nhật ký sử dụng AI trong quá trình làm bài
└── assets/
    └── LOGO CLB KẾT NỐI (1).png   # Logo của CLB
```

---

## 🚀 Hướng dẫn mở và chạy

Dự án **không cần cài đặt** bất kỳ phần mềm nào. Chỉ cần:

1. **Tải về** toàn bộ thư mục `BTL_WED`
2. **Mở file** `index.html` bằng trình duyệt (Chrome, Firefox, Edge...)
   - Chuột phải vào `index.html` → **Mở bằng** → Chọn trình duyệt
3. Trang web sẽ hiển thị hoàn chỉnh ✅

> **Lưu ý:** File `assets/LOGO CLB KẾT NỐI (1).png` phải nằm đúng vị trí trong thư mục `assets/` để logo hiển thị.

## ✨ Tính năng nổi bật

- ✅ **Responsive** – Hiển thị tốt trên máy tính, tablet và điện thoại
- ✅ **Form đăng ký trực tiếp** – Không cần qua Google Form bên ngoài
- ✅ **Sticky header** – Thanh điều hướng dính khi cuộn trang
- ✅ **Smooth scroll** – Cuộn mượt khi click menu
- ✅ **Accessibility cơ bản** – Skip link, aria-label, focus visible
- ✅ **CSS thuần** – Không dùng framework, dễ đọc và học

## 🛠️ Công nghệ sử dụng

| Công nghệ | Mục đích |
|---|---|
| HTML5 | Cấu trúc trang |

| JavaScript (vanilla) | Xử lý form đăng ký |

## ⚠️ Giới hạn đã biết

- Form đăng ký **chưa kết nối backend** – dữ liệu không được lưu vào cơ sở dữ liệu
- **Fanpage** chưa có link thật (đang để `#`)
- Chưa có **dark mode**
- Chưa có **hamburger menu** cho mobile (menu co lại tự nhiên)
